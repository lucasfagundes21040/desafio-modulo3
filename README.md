# Desafio Módulo III - Peaky Blinders Wiki

Página estilo Wikipédia sobre a série Peaky Blinders, criada para praticar 
semântica e acessibilidade em HTML.

## Sobre o projeto
Recriação de um layout de wiki utilizando tags semânticas do HTML5.

## Conteúdos praticados
- Tags semânticas: header, nav, main, aside, section e footer
- Âncoras internas para navegação entre seções
- Tabelas
- Listas e links
- Acessibilidade (atributo alt em imagens)

## Como visualizar
Baixe os arquivos e abra o `index.html` no navegador.
